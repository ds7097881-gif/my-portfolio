# 🏛️ Public Grievance Redressal System
## जन शिकायत निवारण प्रणाली

A **fully functional, live-time** Public Grievance Redressal and Feedback System built with pure HTML, CSS, and JavaScript.

---

## 🚀 How to Run

Simply open `index.html` in any modern web browser (Chrome, Firefox, Edge).

**No installation required. No server needed. Works offline.**

---

## ✅ Features

### 🏠 Home Page
- Live clock (real-time)
- Live statistics counter (animated)
- Category quick-select cards
- **🔴 LIVE Activity Feed** — auto-updates every 10 seconds

### 📝 Submit Grievance
- Full applicant form (Name, Mobile, Email, Aadhaar, Address)
- Department/Category selection (10 categories)
- Priority levels (High / Medium / Low)
- File upload with drag & drop
- **OTP Mobile Verification** (demo OTP displayed on screen)
- Declaration checkbox
- **Auto-generated Token Number** after submission
- Printable receipt

### 🔍 Track Status
- Search by **Token Number** or **Mobile Number**
- Full grievance details
- **Timeline view** — shows every status change with date/time

### ⭐ Feedback System
- Star ratings (4 categories)
- Resolution status
- Comments/suggestions
- Recommendation button
- Submitted feedbacks saved to database

### 📊 Live Dashboard
- 6 live stat counters
- Category-wise bar chart
- Priority distribution
- Recent grievances table (sortable)

### 🔐 Admin Panel
- Secure login (admin / admin123)
- Search + filter grievances (by status, priority, keyword)
- **Update grievance status** with remarks
- Delete grievances
- **Export to CSV**

---

## 🔴 LIVE Simulation
The system auto-simulates real-time activity:
- New grievances are filed automatically
- Status updates happen automatically
- Live feed ticker updates

## 💾 Data Storage
All data is stored in **localStorage** — no backend required. Data persists between page refreshes.

- Google Fonts (Rajdhani, JetBrains Mono)
- localStorage for data persistence
